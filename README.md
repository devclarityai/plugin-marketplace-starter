# Plugin Marketplace Starter

A template repository for a Claude Code plugin marketplace. Use it as the starting point for distributing your team's skills: create your own copy from this template, rename the marketplace, and add your plugins.

It ships two example plugins:

- `simple-demo`: one skill (`address-me`) to confirm the marketplace works end to end.
- `dev-toolkit`: three small example skills (`commit-message`, `pr-summary`, `changelog-entry`) to copy as a template.
