This is the demo skill that proves the marketplace is wired up correctly.

1. Ask the user what they'd like to be called (a name or nickname).
2. Greet them by it, and confirm that the marketplace and the `simple-demo` plugin are installed and working.
3. Tell them they can now delete this demo plugin (`plugins/simple-demo`) and start adding their own skills — point them at the `dev-toolkit` plugin as a template.

Keep it to two or three sentences. The whole point is to prove the end-to-end path works.
